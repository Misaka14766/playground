# 🎲 爱恩斯坦棋 (Einstein würfelt nicht!)

> 骰子决定命运，策略决定胜负

爱恩斯坦棋（简称 EWN）是一款两人对弈的抽象策略棋类游戏。双方各有 6 枚编号为 1-6 的棋子，每次掷骰子后移动对应编号的棋子，率先将任意一枚棋子移至对角或吃光对方所有棋子者获胜。

## 游戏特性

- **🤝 人人对战** — 双人本地对战
- **🤖 人机对战** — 内置三档难度 AI：入门 / 普通 / 困难
- **👁 AI 自战** — 观看两方 AI 对弈（内置 vs 内置，或外部 vs 外部）
- **🔌 外部 AI 接入** — 通过 WebSocket 接入自定义 AI 进程（v5 通用池架构）
- **📊 AI 状态面板** — 实时查看所有已连接的外部 AI 详细信息

## 文件说明

| 文件 | 说明 |
|------|------|
| [index.html](./index.html) | 游戏主体，纯前端单文件，浏览器直接打开即可运行 |
| [ai_server.py](./ai_server.py) | WebSocket 中继服务（v5），桥接浏览器与外部 AI 进程 |
| [ai_example.py](./ai_example.py) | 外部 AI 接入示例，含随机 / 贪心 / Minimax 三种策略 |

## 快速上手

### 直接玩（推荐）

用浏览器直接打开 `index.html` 即可开始人人对战或人机对战。

### 外部 AI 模式

```bash
pip install websockets

python ai_server.py        # 启动中继服务（默认 localhost:8765）
python ai_example.py       # 另开终端，启动示例 AI
```

然后在浏览器游戏中选择对应玩家为「外部AI」即可。

> **v5 架构说明**：外部 AI 不再需要预声明颜色。所有 AI 连接到通用池，游戏开始时由前端指定每方使用哪个 AI。

### 自定义 AI

参考 `ai_example.py` 的实现，编写自己的 AI 逻辑：

1. 连接到 `ws://localhost:8765/ai`
2. 发送注册消息 `{type: "register", name: "我的AI", strategy: "..."}`
3. 收到 `move_request` 消息（含当前棋盘、骰子点数、合法走法列表）
4. 返回 `move_response` 消息（指定要走的棋子和目标位置）

**消息协议详见游戏内的「🔌 接口」页面。**

## 项目结构（v5）

```
浏览器 (index.html)
    │
    ▼ WebSocket
ai_server.py (中继服务)
    │
    ├──► AI 进程 A (ai-abc123)  ← 随机策略
    ├──► AI 进程 B (ai-def456)  ← 贪心策略
    └──► AI 进程 C (ai-ghi789)  ← 你的自定义 AI
```

## 游戏规则摘要

- 棋盘 5×5，红方起始区左上三角形（A1,A2,A3,B1,B2,C1），蓝方右下三角形（C5,D4,D5,E3,E4,E5）
- 掷骰子决定走哪枚棋子（点数 = 编号）；对应编号已被吃则改走编号最接近的棋子
- 红方向右、下、右下移动；蓝方向左、上、左上移动
- 吃子规则同国际象棋（走到对方棋子格即吃掉）
- **获胜条件**：己方任意棋子到达对方对角（红→E5，蓝→A1）或吃光对方全部棋子
