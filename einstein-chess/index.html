游戏规则

爱恩斯坦棋（EWN · Einstein würfelt nicht!）是由 Ingo Althöfer 设计的双人策略骰子棋盘游戏

🎯 基本规则

棋盘

5×5 方格棋盘。红方出发区在左上角，蓝方出发区在右下角。

棋子

双方各 6 枚棋子，编号 1-6。开局时按固定位置摆放：

  • 红方：A1、A2、A3、B1、B2、C1（左上三角形区域）
  • 蓝方：C5、D4、D5、E3、E4、E5（右下三角形区域）

走法

  • 轮流掷骰子，走与点数对应编号的棋子
  • 若对应棋子已被吃，走编号最接近的棋子
  • 若两侧都有，可自选一个走

移动方向

  • 红方：向右、向下、向右下（趋向右下角）
  • 蓝方：向左、向上、向左上（趋向左上角）

🏆 胜利条件

两种获胜方式

  • 率先将己方棋子到达对方出发区角点（右下角/左上角）
  • 将对方全部棋子吃光

对战制度

  • 每盘每方用时 4 分钟，超时判负
  • 每轮最多 7 盘，先胜 4 盘获胜
  • 轮流先手（甲方：1、4、5 盘；乙方：2、3、6、7 盘）
  • 对弈结果只有胜负，没有和棋

特殊策略

有时吃掉本方棋子也是好策略——可增加其他棋子的走动灵活性！

AI 外部接口文档 v4

多后端架构 — 支持多个外部 AI 同时连接并分别控制红/蓝方

📡 连接方式

先启动 AI 中继服务，然后 AI 进程按颜色连接不同路径：

WebSocket 端点：
游戏端: ws://localhost:8765/game
AI(通用): ws://localhost:8765/ai
AI(红方): ws://localhost:8765/ai/red
AI(蓝方): ws://localhost:8765/ai/blue

📝 AI 注册协议 (v4 新增)

AI → Server (注册)
{
  "type": "register",
  "color": "blue",
  "name": "GreedyBot"
}
Server → AI (确认)
{
  "type": "registered",
  "ai_id": "blue-a1b2c3",
  "color": "blue",
  "message": "已注册为 蓝方 AI"
}

📨 消息协议

游戏 → AI（请求决策）
{
  "type": "move_request",
  "current_player": "blue",
  "dice": 3,
  "valid_moves": [...],
  ...
}
AI → 游戏（返回决策）
{
  "type": "move_response",
  "piece_id": 3,
  "from": [2, 3],
  "to": [1, 2]
}

🔄 多AI对战示例

# 终端1: 启动服务
python ai_server.py

# 终端2: 红方用 Greedy AI
python ai_example.py --server ws://localhost:8765/ai/red \
                     --strategy greedy

# 终端3: 蓝方用 Expectiminimax AI
python ai_expectiminimax.py --server ws://localhost:8765/ai/blue

# 浏览器: 选择红方=外部AI(GreedyBot)，蓝方=外部AI(ExpectiBot)

🚀 快速开始

# 1. 安装依赖
pip install websockets

# 2. 启动 AI 中继服务
python ai_server.py

# 3. 运行外部 AI（可选）
python ai_example.py --server ws://localhost:8765/ai/red --strategy greedy

# 4. 在游戏中选择双方控制器，开始对弈
