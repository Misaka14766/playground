游戏规则

爱恩斯坦棋（EWN · Einstein würfelt nicht!）是由 Ingo Althöfer 设计的双人策略骰子棋盘游戏

🎯 基本规则

棋盘

5×5 方格棋盘。红方出发区在左上角，蓝方出发区在右下角。

棋子

双方各 6 枚棋子，编号 1-6。开局时可在己方出发区（左上/右下 3×3 区域）自由摆放。

走法

  • 轮流掷骰子，走与点数对应编号的棋子
  • 若对应棋子已被吃，走编号最接近的棋子
  • 若两侧都有，可自选一个走

移动方向

  • 红方：向右、向下、向右下（趋向右下角）
  • 蓝方：向左、向上、向左上（趋向左上角）

🏆 胜利条件

两种获胜方式

  • 率先将己方棋子到达对方出发区角点（右下角/左上角）
  • 将对方全部棋子吃光

对战制度

  • 每盘每方用时 4 分钟，超时判负
  • 每轮最多 7 盘，先胜 4 盘获胜
  • 轮流先手（甲方：1、4、5 盘；乙方：2、3、6、7 盘）
  • 对弈结果只有胜负，没有和棋

特殊策略

有时吃掉本方棋子也是好策略——可增加其他棋子的走动灵活性！

🎲 骰子选棋规则详解

若骰子显示 N，但编号 N 的棋子已被移出：

  • 先找比 N 小且最接近的棋子（N-1, N-2…）
  • 再找比 N 大且最接近的棋子（N+1, N+2…）
  • 若两侧均有可选棋子，玩家可自由选择
  • 若只有一侧有棋子，必须走那枚

示例：骰子点数为 4，棋子 4 和 5 均已被吃，则可走棋子 3 或 6（若两者都在棋盘上）。

AI 外部接口文档

通过 WebSocket 协议，让外部进程（Python/Node.js/任意语言）接入本游戏充当 AI 玩家

📡 连接方式

需要先启动 AI 中继服务（ai_server.py），然后在游戏中选择「外部AI」模式

WebSocket 服务地址：
ws://localhost:8765
HTTP API（备选）：
http://localhost:8765/move

📨 消息协议

游戏 → AI（请求决策）
{
  "type": "move_request",
  "board": [
    [{"color":"red","id":1}, null, ...],
    ...
  ],
  "dice": 3,
  "current_player": "blue",
  "valid_moves": [
    {"piece_id":3, "from":[2,3], "to":[1,3]},
    {"piece_id":3, "from":[2,3], "to":[2,2]},
    {"piece_id":3, "from":[2,3], "to":[1,2]}
  ],
  "game_state": {
    "red_captured": [2,4],
    "blue_captured": [],
    "move_count": 12,
    "time_left": {"red":210, "blue":195}
  }
}
AI → 游戏（返回决策）
{
  "type": "move_response",
  "piece_id": 3,
  "from": [2, 3],
  "to": [1, 2]
}

// 或者使用简化格式：
{
  "type": "move_response",
  "move_index": 0
}

// 错误时返回：
{
  "type": "error",
  "message": "无法计算走法"
}
