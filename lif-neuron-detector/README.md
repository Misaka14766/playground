# LIF 神经元脉冲模式检测器

> 基于 STDP 的脉冲时序依赖可塑性演示 · 类脑计算教学工具

## 简介

这是一个完全运行在浏览器中的脉冲神经网络（SNN）交互式仿真器，用于演示：

- **LIF 神经元模型**（Leaky Integrate-and-Fire）
- **STDP 学习规则**（Spike-Timing-Dependent Plasticity）
- **同步检测**：输入 A 和 B 时间差 < 5ms 时，输出神经元 C 才会发放脉冲

## 网络结构

```
A (输入神经元) ──w(A→C)──┐
                          ├──► C (输出神经元)
B (输入神经元) ──w(B→C)──┘
```

## 功能

- 🧠 实时神经网络拓扑可视化（Canvas 动画）
- 📊 膜电位时序图 / 脉冲栅格图 / STDP 权重变化图
- 🎛️ 可调节参数：发放频率、同步概率、学习率、LIF 阈值
- 📈 统计面板：发放次数、同步检测率、突触权重进度条

## 使用方法

直接用浏览器打开 `index.html`，无需任何依赖或服务器。

1. 点击 **运行** 开始仿真
2. 调整 **同步概率** 滑块，观察同步输入对权重的影响
3. 调整 **学习率** 和 **LIF 阈值**，体验参数调节的微妙之处
4. 观察 STDP 权重变化图，理解"同步=增强"的学习机制

## 核心原理

### LIF 模型

```
τ · dV/dt = -(V - V_rest) + I_syn
```

当膜电位 V 超过阈值时，神经元"发放"脉冲，电位重置。

### STDP 规则

- **前 → 后**（pre before post）：权重增强（LTP）
- **后 → 前**（post before pre）：权重减弱（LTD）

```
ΔW = A+ · exp(-Δt / τ+)   if Δt > 0  (LTP)
ΔW = -A- · exp(Δt / τ-)   if Δt < 0  (LTD)
```
